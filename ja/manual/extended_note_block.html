Extended Note Block の基礎 ​

Extended Note Block はこの MOD の核となるブロックです。バニラの音符ブロックと比較して、より精密な制御と豊富な機能を提供します。

設置と基本設定 ​

  • 設置: バニラの音符ブロックと同様に Extended Note Block を設置します。
  • インターフェースを開く: ブロックを 右クリック すると設定画面が開きます。

パラメータの詳細 ​

基本設定画面では、以下のパラメータを設定できます：

1. 音程 (Note) ​

  • 範囲: 0 - 127 (MIDI 規格に対応)。
  • バニラの 0-24 の制限とは異なり、ここでは10オクターブにわたる音を再生できます。

2. 力度 (Velocity) ​

  • 範囲: 0 - 127。
  • 音の大きさ（音量）を制御します。

3. 持続音 (Sustain) ​

  • 単位: Tick (1/20秒)。
  • 音波が終了するまでの持続時間を制御します。

4. 再生遅延 (Delay) ​

  • 単位: ミリ秒 (ms)。
  • これは リアルタイム遅延 設定です。レッドストーン信号でブロックが起動されると、指定されたミリ秒数だけ待機してから発音します。
  • これにより、レッドストーンリピーター（0.1秒単位）よりも細かい音楽的なタイミング調整が可能になります。

5. フェードイン/アウト (Fade In/Out) ​

  • 単位: Tick。
  • 音を滑らかに出現または消失させ、不自然な途切れ方を防ぎます。
