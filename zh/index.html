Extended Note Block ​

WARNING

本文档使用 AI 创作。

Extended Note Block 专为 Fabric 平台打造，旨在为 Minecraft 带来专业级的音乐创作体验，是音乐家和红石工程师的理想选择。

核心功能 ​

  • 扩展音符盒: 全面支持 MIDI 音高 (0-127)、力度、延音、延迟以及渐变控制。
  • 高级模式: 可视化编辑音量与音高包络线，并支持通过数学表达式 (x, y, z, t) 动态控制声源移动。
  • 无线红石: 利用发送器与接收器，实现全图范围的红石信号无缝传输。
  • 指挥棒: 轻松框选区域，批量编辑范围内的音符盒属性。
  • 平滑移动: 通过指令使玩家在指定方向上进行丝滑的移动操作。

安装指南 ​

  1. 安装 Fabric Loader 和 Fabric API。
  2. 下载 Extended Note Block 并放入 mods 文件夹。

推荐配置

强烈建议搭配 Carpet Mod 使用，以获得更精准的红石时序和更佳的性能体验。
