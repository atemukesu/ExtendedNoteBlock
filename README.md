**Extended Note Block** 是一个专为 Minecraft Fabric 平台设计的模组，它为游戏引入了全新的音乐创作体验。该模组添加了一个功能强大的
**扩展音符盒 (Extended Note Block)** 方块，将原版简单的音符系统升级为完整的音乐制作工具。
