# Extended Note Block ユーザーマニュアル

**Extended Note Block** MOD へようこそ！このマニュアルでは、基本的な Extended Note Block から高度なエンベロープ編集、無線レッドストーンまで、MOD のすべての機能を詳しく解説します。

## 章の概要

初めて使用される方は、以下の順序で読むことをお勧めします：

1. **[Extended Note Block の基礎](extended_note_block.md)**
   - 音程 (0-127)、ベロシティ、サステイン、再生遅延の設定方法を学びます。
2. **[高度なモードとエンベロープ](advanced_mode.md)**
   - 視覚的なインターフェースを使用して音量と音程のエンベロープを編集する方法、および音源移動の設定方法を学びます。
3. **[無線レッドストーンシステム](wireless_redstone.md)**
   - グローバル信号伝送について。
4. **[コンダクターワンド](conductor_wand.md)**
   - 領域選択と一括編集について。
5. **[サウンドパック管理](sound_packs.md)**
   - カスタムサンプルのインポートについて。
6. **[スムーズ移動コマンド](smooth_move.md)**
   - `/smoothmove` を使用してプレイヤーや生物を指定した方向に滑走させる方法。
