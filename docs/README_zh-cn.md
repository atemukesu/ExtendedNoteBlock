**Extended Note Block** 是一个专为 Fabric 平台设计的模组，致力于为 Minecraft 引入专业级的音乐创作体验。

### 核心功能
*   **扩展音符盒**: 支持 MIDI 音高 (0-127)、力度、延音、延迟和渐变控制。
*   **高级模式**: 可视化音量、音高包络线编辑，以及基于数学表达式的声源移动 (`x`, `y`, `z`, `t`)。
*   **无线红石**: 全局范围的红石信号传输（发送器/接收器）。
*   **指挥棒**: 支持选区并批量编辑区域内音符盒。
*   **平滑移动**: 平滑移动指令，使玩家朝某个方向平滑移动。

### 安装指南

1.  安装 [Fabric Loader](https://fabricmc.net/) 和 [Fabric API](https://modrinth.com/mod/fabric-api)。
2.  下载 **Extended Note Block** 并放入 `mods` 文件夹。
3.  *(可选)* 推荐安装 [Carpet Mod](https://github.com/gnembon/fabric-carpet)。
