# 扩展音符盒基础

**Extended Note Block** 是本模组的核心。与原版音符盒相比，它提供了更精准的控制和更丰富的功能。

## 放置与基础设置

- **放置**: 像放置原版音符盒一样放置 **扩展音符盒 (Extended Note Block)**。
- **打开界面**: **右键点击** 方块即可打开其配置界面。

![Extended Note Block GUI](/docs/assets/sh1.png)

## 参数详解

在基础设置界面中，你可以配置以下参数：

### 1. 音高 (Note)
- **范围**: 0 - 127 (对应 MIDI 标准)。
- 不同于原版的 0-24 限制，这里你可以播放横跨 10 个八度的声音。

### 2. 力度 (Velocity)
- **范围**: 0 - 127。
- 控制声音的大小（音量）。

### 3. 延音 (Sustain)
- **单位**: 刻 (Tick, 1/20秒)。
- 控制声波结束前的持续时间。

### 4. 播放延迟 (Delay)
- **单位**: 毫秒 (ms)。
- 这是一个**实时延迟**设置。当红石信号激活方块时，它会等待指定的毫秒数后再发声。
- 这允许你进行比红石中继器（0.1s 粒度）更精细的音乐对齐。

### 5. 淡入/淡出 (Fade In/Out)
- **单位**: 刻 (Tick)。
- 让声音平滑地出现或消失，避免生硬的切断感。
