# Extended Note Block 使用手册

欢迎使用 **Extended Note Block** 模组！本手册将带您深入了解模组的所有功能，从基础的扩展音符盒到高级的包络线编辑和无线红石。

## 章节概览

如果您是第一次使用，建议按照以下顺序阅读：

1. **[扩展音符盒基础](extended_note_block.md)**
   - 了解如何设置音高 (0-127)、力度、延音和播放延迟。
2. **[高级模式与包络线](advanced_mode.md)**
   - 学习如何使用可视化界面编辑音量和音高包络，以及配置声源移动。
3. **[无线红石系统](wireless_redstone.md)**
   - 全局信号传输。
4. **[指挥棒](conductor_wand.md)**
   - 区域选择与批量编辑。
5. **[音色包管理](sound_packs.md)**
   - 导入自定义采样。
6. **[平滑移动指令](smooth_move.md)**
   - 使用 `/smoothmove` 让玩家或生物按指定方向滑行。
