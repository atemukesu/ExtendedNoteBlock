# Extended Note Block User Manual

Welcome to the **Extended Note Block** mod! This manual will take you deep into all the features of the mod, from the basic Extended Note Block to advanced envelope editing and wireless Redstone.

## Chapter Overview

If this is your first time using it, we recommend reading in the following order:

1. **[Extended Note Block Basics](extended_note_block.md)**
   - Learn how to set pitch (0-127), velocity, sustain, and playback delay.
2. **[Advanced Mode & Envelopes](advanced_mode.md)**
   - Learn how to use visual interfaces to edit volume and pitch envelopes, as well as configure sound source movement.
3. **[Wireless Redstone System](wireless_redstone.md)**
   - Global signal transmission.
4. **[Conductor's Wand](conductor_wand.md)**
   - Region selection and batch editing.
5. **[Sound Pack Management](sound_packs.md)**
   - Importing custom samples.
6. **[Smooth Move Command](smooth_move.md)**
   - Using `/smoothmove` to make players or creatures glide in a specified direction.
