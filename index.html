Extended Note Block ​

WARNING

This document is translated by AI.

Start your professional music creation journey in Minecraft with Extended Note Block. Designed for the Fabric loader, this mod introduces advanced tools for musicians and redstone engineers alike.

Key Features ​

  • Extended Note Blocks: Full control over MIDI pitch (0-127), velocity, sustain, delays, and fade effects.
  • Advanced Mode: Visualize volume and pitch envelopes, and animate sound sources using mathematical expressions (x, y, z, t).
  • Wireless Redstone: transmit Redstone signals globally with Transmitters and Receivers.
  • Conductor's Wand: Select areas and batch-edit Note Blocks with ease.
  • Smooth Motion: Execute smooth movement commands to glide players in specific directions.

Installation ​

  1. Install Fabric Loader and Fabric API.
  2. Download Extended Note Block and place it in your mods folder.

Recommended

Carpet Mod is highly recommended to ensure precise timing and performance.
